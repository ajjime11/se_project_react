What to Wear (WTWR) — Frontend

This is the React frontend for the WTWR application, a weather‑based outfit recommendation tool. The app fetches real‑time weather data, displays dynamic clothing suggestions, and allows users to manage their wardrobe through an intuitive UI.

🚀 Live Demo
https://se-project-react-blue.vercel.app/ (se-project-react-blue.vercel.app in Bing)

⚠️ Important Note About Load Time
The backend is hosted on a free tier service that sleeps when inactive.
The first request may take a few seconds to wake the server.  
Once awake, the app runs normally and responds quickly.
